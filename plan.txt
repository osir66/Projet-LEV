Installer : 
   - py -m venv .venv : pour installer venv 
   - .\.venv\Scripts\activate aller dans le venv 
   - pip install fastapi uvicorn : installer fastAPI 
   - uvicorn main:app --reload : lancer son serv web 
   - ouvrir port + ip : uvicorn main:app --host 0.0.0.0 --port 8000
